# AVI a MP4

App Android sin anuncios para convertir videos `.avi` a `.mp4` (H.264 + AAC) usando Media3 Transformer y la aceleración por hardware del teléfono.

- Elige uno o varios videos, o usa **Compartir / Abrir con** desde la galería o el explorador.
- Los MP4 se guardan en `Películas/AVIaMP4`.
- Android 10 o superior.

GitHub Actions compila el APK en cada push y lo publica en **Releases**.
